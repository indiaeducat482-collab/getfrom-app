# GetFROM V2 Complete Platform
Features: Supabase Login/Register, Form Builder, AI Create smart generator, 12 editable templates, Visual App Builder, Save/Publish, My Apps/My Forms and Super Admin.

Setup:
1. Run supabase/GetFROM-V2-Database.sql in Supabase SQL Editor.
2. Register your account.
3. Run the final UPDATE command with your email to make yourself Super Admin.
4. Upload this folder to GitHub.
5. Enable GitHub Pages.

Note: AI Create is a smart template-based generator. Real LLM integration should be added through a secure server-side/Edge Function.
