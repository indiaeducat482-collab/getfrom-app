# GetFROM - Supabase Connected
Your Supabase URL and publishable key are configured.

## Deploy
1. Upload all files to a GitHub repository.
2. Enable GitHub Pages.
3. In Supabase Authentication > URL Configuration, add your GitHub Pages URL.
4. If email confirmation is enabled, confirm the registered email before login.

## Included
- Real Supabase Auth
- Real forms database
- Published public forms
- Real submission storage
